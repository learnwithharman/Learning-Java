# Learning Java

Welcome to my Java learning repository! This project tracks my progress through various Java concepts, from fundamental syntax to complex object-oriented systems and mini-applications.

---

## 1. Foundations & Basics
The following programs cover the bedrock of Java, focusing on boilerplate structure, variable declarations, and fundamental operators.
- [HelloWorld.java] - Standard entry point and basic console output.
- [variables.java] - Introduction to data types and variable initialization.
- [Operators.java] - Demonstration of arithmetic, logical, and assignment operators.
- [Main.java] - A central class for executing various experiments.

## 2. Control Flow & Logic
These scripts explore decision-making in Java using conditional statements and branching logic.
- [JavaConditionsNotes.java] - Detailed notes and examples on if-else and switch-case structures.
- [workingdays.java] - Simple logic to determine operational days.
- [AdvPassChecker.java] - An advanced password validation utility with multiple criteria.
- [PasswordChecker.java] - Basic implementation of password verification.

## 3. Loops & Iteration
Mastering repetitive tasks through for, while, and do-while loops, including enhanced for-loop syntax.
- [LoopsInJava.java] - Comprehensive guide to standard iteration techniques.
- [EnhancedForLoopExample.java] - Using the "for-each" loop for cleaner collection traversal.
- [DynamicInit.java] - Initializing values dynamically within a loop structure.

## 4. Mathematical Algorithms & Recursion
Focuses on numerical problem-solving and the implementation of recursive functions.
- [FactorialBig.java] - Computing large factorials using efficient algorithms.
- [factorialrec.java] - Classic recursive implementation of the factorial function.
- [sumOfNrec.java] - Calculating the sum of the first N natural numbers using recursion.
- [isPrime.java] - Prime number verification and mathematical logic.
- [Geometric_Progression.java] - Generating and analyzing GP sequences.
- [SumTwoNumbers.java] - Basic arithmetic operation demonstration.
- [area.java] - Calculating areas of various geometric shapes.
- [areaofrectangle.java] - Specific implementation for rectangle area logic.

## 5. Arrays & Data Collections
Exploring the organization of data in one-dimensional, multi-dimensional, and jagged arrays.
- [array.java] - Fundamental array operations and indexing.
- [multidimarray.java] - Handling data in 2D grids/matrices.
- [arrays3d.java] - Understanding three-dimensional data storage.
- [jaggedArray.java] - Working with non-uniform multi-dimensional arrays.
- [maxElementArr.java] - Finding the maximum value within an array.
- [reverseArr.java] - Efficiently reversing the elements of a collection.
- [arrayofobjects.java] - Storing class instances within an array structure.

## 6. Object-Oriented Programming (OOP)
Deep dives into the core pillars of Java: Classes, Objects, Inheritance, and Encapsulation.
- [ObjClass.java] - Basic class and object instantiation.
- [PersonClass.java] - Modeling real-world entities using classes.
- [multilevelInheritance.java] - Demonstration of parent-child-grandchild relationships.
- [accessModifiers.java] - Exploring public, private, protected, and default visibility.
- [AccessDemo.java] - Practical application of access control.
- [TestAccess.java] - Cross-file testing for access modifiers and scoping.
- [animalSound.java] - Polymorphism demonstration through animal behavior.
- [LibraryDemo.java] - Modeling a library system using OOP principles.
- [methodoverloading.java] - Enhancing flexibility with multiple method signatures.

## 7. Applied Java: Mini Projects & Systems
Real-world scenarios implemented as console-based applications and management systems.
- [atm.java] - A functional ATM simulation with deposit and withdrawal options.
- [electronicshop.java] - Inventory management system for an electronics store.
- [RestaurantOrderSystem.java] - Orchestrating customer orders and billing.
- [MovieTicketBooking.java] - User-friendly seat selection and booking flow.
- [BookingCinema.java] - Core logic for cinema scheduling and management.
- [ShoppingCart.java] - E-commerce logic for adding items and calculating totals.
- [BankingSysOOPS.java] - Robust banking system using object-oriented architecture.
- [MadLibsGame.java] - Fun interactive game demonstrating string concatenation.
- [StudentAttendanceSystem.java] - Tracking and managing student participation.
- [Calcclass.java] - Object-oriented approach to building a calculator.
- [calcwithclass.java] - Further refinement of the calculator implementation.

## 8. String Manipulation
Understanding the behavior of strings and how to traverse character sequences.
- [stringDemo.java] - Essential methods within the String class.
- [StringTraversal.java] - Manual iteration and analysis of character data.

## 9. Data Structures
Introduction to fundamental data organization techniques.
- [stacks.java] - Basic implementation of a Last-In-First-Out (LIFO) stack.
